# fb-clone-website

This project is a "Facebook website clone" that I created while learning and practicing "Git and GitHub" during our GitHub tutorial.

The main purpose of this project was to understand how a real-world website can be structured and how to manage a development project using Git and GitHub. While building this clone, I practiced creating a project repository, organizing files, making changes, committing updates, and working with GitHub.

About the Project

This project recreates the basic look and layout of a Facebook-style social media website. It was developed as a learning project to improve my understanding of "HTML, CSS, web page structure, and Git/GitHub workflow".

Through this project, I learned how to:

* Create and organize a web development project
* Build a webpage using HTML
* Style the webpage using CSS
* Create a layout inspired by a social media platform
* Use Git for version control
* Create and manage a GitHub repository
* Make commits and track changes
* Push project files to GitHub
* Understand the basic Git and GitHub workflow

Technologies Used

* HTML – Used to create the structure of the website
* CSS – Used to design and style the webpage
* Git – Used for version control
* GitHub – Used to store and manage the project repository

Purpose

The goal of this project was not to create a fully functional Facebook application, but to practice "frontend development and GitHub fundamentals" by building a website inspired by Facebook's interface.

This project helped me understand how individual files and changes can be managed using Git and how a project can be uploaded and maintained on GitHub.

What I Learned

Building this project gave me practical experience with both "web development and version control". I learned how to work with repositories, make commits, push changes, and organize my code while developing a website.

It was a useful hands-on project for improving my confidence with **HTML, CSS, Git, and GitHub**.
